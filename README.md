# Changelog Website

This repository contains a simple HTML website displaying a changelog for recent updates and projects. The website is styled using CSS and includes a timeline of events showcasing recent changes and announcements.

## Features
- A responsive design with a timeline of changelog items.
- Displays events with dates, titles, and descriptions.
- A button linking to the complete changelog.
- Animated timeline with glowing effects.

## Sections Overview

### Header
- Displays the title "Changelog" and a subtitle "Here's everything we have shipped in the past few days."

### Timeline
- Lists important updates with the following structure:
  - **Date:** The date of the update.
  - **Event:** A brief description of the event.
  - Each item features a circle marker with a glowing effect to indicate the update.

### Button
- A button styled with a gradient background allowing users to access the complete changelog.

## How to Access the Website
To view the website:
1. Clone this repository.
2. Open the `index.html` file in your browser.

## Roadmap
This website serves as a simple showcase for displaying updates in a timeline format. You can use it as inspiration for your own changelog or update system. For more details, you can check out the [Changelog Component Example on roadmap.sh](https://roadmap.sh/projects/changelog-component).
